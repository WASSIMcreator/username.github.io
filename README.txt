AL-BARAKA — Version corrigée

Ouvrez index.html dans Chrome ou Edge. Gardez index.html, style.css et script.js dans le même dossier.
Si la page s'affiche sans design, vérifiez que style.css est bien dans le même dossier et que vous avez extrait le ZIP (pas ouvert le HTML seul depuis l'archive).

Prototype : filtres produits, panier, total, design responsive. Les prix et illustrations sont fictifs. Le formulaire ne sauvegarde pas les e-mails. Aucune base de données ni paiement en ligne n'est configuré. Pour activer WhatsApp, remplacez le numéro de démonstration dans script.js par votre numéro au format international sans + ni espaces.
La police web nécessite Internet; sinon une police de secours est utilisée.
